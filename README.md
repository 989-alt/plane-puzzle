# 한 판! 돌리고 뒤집기

「한 판! 돌리고 뒤집기」는 밀기, 뒤집기, 돌리기로 조각을 옮겨 판을 빈틈없이 채우는 2D 퍼즐 웹앱입니다.
초등 3~4학년군 수학 「평면도형의 이동」 수업에서 씁니다.

- **[4수03-04]** 구체물이나 평면도형의 밀기, 뒤집기, 돌리기 활동을 통하여 그 변화를 이해한다.
- **[4수03-05]** 평면도형의 이동을 이용하여 규칙적인 무늬를 꾸밀 수 있다.

라이브 주소: https://989-alt.github.io/plane-puzzle/

서버, DB, 외부 API, 외부 CDN을 쓰지 않습니다. 글꼴도 저장소에 함께 들어 있습니다.
이름 같은 개인정보는 받지 않습니다. 브라우저 localStorage에는 `pp.` 접두사로 최고 점수, 푼 문제 수, 조작 안내를 다시 볼지만 저장합니다.

## 놀이 방법

1. **시작**을 누릅니다. 처음 들어오면 조작 안내(밀기, 뒤집기, 돌리기) 3장이 먼저 나옵니다.
2. **밀기**: 조각을 끌어 판 위에 놓습니다. 판 밖에 놓으면 조각은 트레이의 가장 가까운 빈자리로 돌아갑니다.
3. **뒤집기·돌리기**: 조각을 톡 누르면(클릭하면) 이동 패널이 열립니다.
   - 위쪽·아래쪽·왼쪽·오른쪽으로 뒤집기
   - 시계 방향 90°·180°·270° 돌리기
   - 시계 반대 방향 90°·180°·270° 돌리기
4. 모든 조각으로 판을 빈틈없이 채우면 정답입니다. 정답이 여러 가지인 문제는 어느 배치든 정답으로 인정합니다.

### 단계

깨끗한 정답을 2번 내면 다음 단계로 올라갑니다.

| 단계 | 단서 | 특징 |
|---|---|---|
| 1단계 · 완성 모양 | 판 위에 빛나는 완성 그림이 나옵니다 | 잘못 놓은 자리는 붉게 표시됩니다 |
| 2단계 · 판 모양 | 판 윤곽만 나옵니다 | |
| 3단계 · 이동 조건 | "이 조각은 뒤집어야/돌려야 맞아요" 카드가 나옵니다 | **숨김 모드**: 버튼을 누르면 이동이 카드 줄에 쌓이고, 판에 놓는 순간 모양이 드러납니다 |
| 4단계 · 최소 이동 | "이동 N번 안에 맞혀 보세요" | 숨김 모드이고, 최소 이동으로 맞히면 별과 보너스 +50을 받습니다 |

- **점수**: (100 + max(0, 60 − 걸린 초)) × 연속 배율입니다.
  - 연속 배율: 1~2연속 ×1, 3연속 ×1.5, 4~5연속 ×2, 6연속 이상 ×3
- **쉬운 단서**: 2단계부터, 60초가 지나면 쓸 수 있습니다.
  - 한 단계 쉬운 단서로 바뀌고, 3·4단계에서는 숨김 모드가 꺼집니다.
  - 쓰면 점수가 절반이 됩니다.
- **도구**
  - 다시 놓기: 조각을 처음 모양과 처음 자리로 돌립니다. 이동 수와 시간은 그대로 이어집니다.
  - 건너뛰기: 연속 기록이 1 줄어듭니다.
  - 도움말: 안내를 보는 동안 시간이 멈춥니다.
- 화면은 가로 16:10입니다. 세로로 들면 "가로로 돌려 주세요"가 나오고 시간이 멈춥니다.
- 터치와 마우스를 모두 지원합니다(Pointer Events). 버튼은 모두 48px 이상입니다.

## 로컬에서 실행

빌드 도구가 없습니다. 저장소 루트에서 정적 서버를 띄우고 브라우저로 엽니다.
`file://`로 열면 문제 은행 JSON을 받지 못하니 반드시 서버로 여세요.

```bash
python -m http.server 8000
# 브라우저에서 http://localhost:8000/
```

`?e2e`를 붙여 열면 시험 훅 `window.__pp`, `window.__ppUi`가 열립니다. 학생용 주소에는 붙이지 않습니다.

## 시험

e2e를 돌리려면 Playwright(Python)와 시스템 Edge가 있어야 합니다: `pip install playwright`.
**메모리가 적은 PC(8GB)에서는 e2e를 한 번에 하나씩** 돌립니다.

```bash
npm test                              # 단위 시험(node --test), 149개
node tools/audit-puzzles.mjs          # 문제 은행 160개 전수 감사(A~F)

python -m http.server 8768            # input_test 전용 서버(다른 창에서)
python tests/e2e/input_test.py        # 끌기·탭·이동 패널·숨김 모드(마우스·터치)

python tests/e2e/flow_test.py         # 게임 흐름·점수·승급·쉬운 단서·도구
python tests/e2e/ui_test.py           # 화면 배치·160문제 배치·확대/스크롤 막기·외부 주소 없음
python tests/e2e/audit_e2e.py         # 12문제를 실제 포인터 조작만으로 풀기(마우스·터치, 24번)
python tests/e2e/visual_review.py     # 1024×768·1280×800 화면 캡처와 자동 확인
```

- 화면 캡처는 `tests/e2e/out/`에 생기며, git에는 올리지 않습니다.
- HUD CSS를 바꿨다면 `python tests/e2e/ui_test.py --dump-rects`로 `tests/ui-rects.json`을 다시 만듭니다.

## 문제 은행 다시 만들기

```bash
node tools/gen-puzzles.mjs            # data/puzzles-s1..s4.json (단계마다 40문제)
node tools/audit-puzzles.mjs          # 다시 만든 은행 감사(실패하면 종료 코드 1)
npm test
```

생성기는 시드가 고정되어 있습니다. 코드가 같으면 몇 번을 돌려도 바이트까지 같은 파일이 나옵니다.
판을 먼저 조각으로 만들고, 조각마다 무작위로 뒤집거나 돌린 모양을 시작 모양으로 삼는 "거꾸로 만들기" 방식입니다.

## 배포

GitHub Pages(master 브랜치 루트)로 배포합니다. 빌드 단계가 없으므로 master에 push하면 바로 반영됩니다.

```bash
git push origin master
gh api repos/989-alt/plane-puzzle/pages/builds/latest   # status 가 built 인지 확인
```

`.nojekyll`이 있어 파일이 그대로 서빙됩니다. `.superpowers/`와 `tests/e2e/out/`은 `.gitignore`에 들어 있습니다.

## 폴더

- `index.html`, `styles/`: 화면
- `src/core/`: 판정, 조각 이동, 해답 탐색, 배치, 점수(DOM 없음)
- `src/view/`: SVG 렌더, 입력, 패널 배치
- `src/ui/`: 화면 전환, HUD, 단서 카드
- `src/main.js`: 게임 흐름
- `data/`: 문제 은행
- `tools/`: 생성기, 감사 도구
- `tests/`: 단위 시험, e2e
